# Carte du graphique de l'audit

- Section : couverture documentaire des fonctions réglementaires
- Question : quels acteurs disposent d'une preuve forte pour la réception, l'émission et l'e-reporting ?
- Conclusion permise : quatorze acteurs ont trois fonctions documentées sur trois, MyUnisoft en a deux sur trois dans les sources retenues.
- Famille : comparaison entre catégories
- Type : barres horizontales, une série, quinze acteurs
- Champs visibles : acteur, nombre de fonctions documentées
- Champs conservés pour l'audit : segment, statut DGFiP, statut de chaque fonction, fonction manquante, principales inconnues, date de revue
- Palette : une racine non neutre, sans légende redondante ni code vert-rouge
- Échelle : zéro à trois, valeurs entières, libellés directs
- Surface finale : rapport Data Analytics validé, puis rendu dans l'application
- Provenance : `src/data/platforms.ts`, `src/data/sources.json`, `src/data/corpus-selection.json`
- Limite : ce compteur n'est pas une note qualité, sécurité, prix ou part de marché.
